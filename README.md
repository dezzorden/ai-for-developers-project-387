## Демо

Приложение разворачивается на Render: **https://call-booking.onrender.com**

План free (см. `render.yaml`) засыпает при бездействии — первый запрос после паузы может занять до минуты, пока контейнер просыпается.

Гость может выбрать формат встречи, удобный день и время в окне двух недель, оставить имя и email. Владелец видит предстоящие встречи и создаёт новые типы событий в разделе «Управление».

## Стек

- **Контракт API** — TypeSpec → OpenAPI 3
- **Backend** — NestJS (Node.js)
- **Frontend** — React + Vite, Mantine UI
- **Деплой** — Render (Docker), GitHub Actions

## Установка

```bash
git clone https://github.com/dezzorden/ai-for-developers-project-387.git
cd ai-for-developers-project-387
npm install
npm --prefix frontend install
npm --prefix backend install
```

Для запуска локально выполните:

```bash
# Mock-API на базе TypeSpec
npm run mock

# Backend (NestJS)
npm run backend:dev

# Frontend (Vite)
npm run frontend:dev
```

## Использование

1. Откройте главную страницу: выберите нужный тип встречи из каталога.
2. На странице бронирования выберите день и свободный слот в пределах 14-дневного окна.
3. Введите имя и email — запись подтверждается мгновенно.
4. Административный раздел доступен по адресу `/admin`: предстоящие встречи и создание новых типов событий.

## План развития

### Готово

- [x] Каталог типов встреч (публичная страница)
- [x] Бронирование слота: день + время + контакты гостя
- [x] Проверка доступности слота (14-дневное окно, сетка 30 минут)
- [x] Админ-панель: список предстоящих встреч
- [x] Админ-панель: создание новых типов событий
- [x] Часы в часовом поясе владельца (Europe/Moscow)
- [x] Контракт API на TypeSpec и mock-сервер
- [x] Docker-образ и деплой на Render

### В плане

- Отмена встречи гостем или владельцем
- Email-уведомления о подтверждении и напоминание о встрече
- Выбор часового пояса гостя при бронировании
- Экспорт встречи в календарь (.ics / Google Calendar)
- Авторизация и защита админ-раздела
- Пагинация и фильтры в списке встреч
- Телеграм-бот для вопросов и записей

### Известные проблемы

- Слоты свободны только в пределах фиксированного окна — при расширении окна нужно пересчитывать границы
- Нет защиты админ-раздела от посторонних (открыт без авторизации)
- Render free plan засыпает при простое — первый запрос может занять до минуты
