# Задача агенту: реализовать сервис «Запись на звонок»

Реализуй законченное веб-приложение с frontend на Next.js и backend на NestJS. Приложение должно собираться в Docker-образ и запускаться в контейнере.

Источники истины:

- API-контракт: `main.tsp`;
- правила предметной области: `docs/domain.md`.

Требования к реализации:

- не добавляй регистрацию и авторизацию;
- используй один заранее заданный профиль владельца;
- реализуй создание типов событий через административный API;
- покажи гостю публичный список типов событий и доступные слоты выбранного типа;
- формируй слоты на ближайшие 14 календарных дней по 30-минутной сетке;
- создавай бронирование только для слота, который остается доступным в момент записи;
- запрети любые пересекающиеся бронирования, в том числе относящиеся к разным типам событий;
- обеспечь атомарность проверки и создания при конкурентных запросах;
- покажи владельцу общий список будущих встреч всех типов;
- валидируй запросы и возвращай статусы и коды ошибок точно по TypeSpec-контракту;
- храни и передавай моменты времени в UTC, а календарное окно рассчитывай в часовом поясе владельца;
- добавь миграции базы данных, автоматические тесты ключевых инвариантов, Dockerfile и инструкцию запуска.

Критерии приемки:

- `npm run typespec:compile` успешно генерирует OpenAPI;
- публичный пользователь проходит путь от списка типов до созданного бронирования;
- повторное или пересекающееся бронирование получает `409 SLOT_UNAVAILABLE`;
- время вне опубликованного 14-дневного окна получает `400 OUTSIDE_BOOKING_WINDOW`;
- административный список содержит будущие встречи всех типов и отсортирован по `startAt`;
- приложение собирается и запускается в Docker-контейнере.
